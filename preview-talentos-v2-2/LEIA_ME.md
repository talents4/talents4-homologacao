# Prévia Talentos 2.2 · sem banco

Esta pasta é uma demonstração independente. **Não usa o Supabase real nem exige login.**

Para publicar apenas a prévia, envie a pasta `preview-talentos-v2-2` inteira à raiz de `talents4/talents4-homologacao` e abra o endereço terminado em `/preview-talentos-v2-2/index.html` depois que o GitHub Pages publicar. Não substitua arquivos da raiz do site com os arquivos internos desta prévia.

Todos os nomes, empresas, currículos, scores e avaliações são fictícios. Os valores reiniciam ao recarregar ou trocar de página. A política `connect-src 'none'` impede conexões de dados, não é uma promessa de persistência. Não preencha dados pessoais reais na demonstração. Links `example.com` são somente exemplos; a tela não envia documentos.

Confira filtros múltiplos, Acompanhamento, Prontos para apresentar, Resumo BW e Radar NectaNet. Os demais switches são cópias sem alterações da interface anterior.

Os testes automatizados foram realizados com simulação de DOM e banco. A conferência de layout, responsividade e teclado no navegador cabe a esta etapa de homologação visual; não foi afirmada como concluída.
