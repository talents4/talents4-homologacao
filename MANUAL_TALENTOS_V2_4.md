# Manual rápido · Talents 4 V2.4

## A leitura diária

1. Abra **Talentos → Meu dia** para ver ações vencidas ou sem próximo passo.
2. Use **Talentos → Talentos** para procurar uma pessoa.
3. Escolha uma visão: **Todos**, **Meus**, **Atenção**, **Em aulas** ou **Prontos**.
4. Combine filtros; o contador mostra quantos registros permanecem no recorte.
5. Use **Lista** no trabalho diário. Use **Tabela completa** para conferir campos da planilha. Use **Cartões** para uma leitura mais visual.

## Ficha lateral

Clique no nome ou em qualquer área vazia da linha. A ficha abre à direita, sem abandonar a lista. As abas Perfil, Seleções, Alemão, Documentos, Histórico e Todos os dados se referem à mesma pessoa.

Edite somente na ficha/modal. O sistema envia apenas campos alterados e preserva campos que não estão visíveis.

## Seleções

Uma seleção é a relação **Talento + Empregador + Vaga**. A etapa da seleção não substitui a etapa do perfil, a documentação ou o andamento do Alemão.

Use **Seleções** para a operação e o próximo passo. Use o quadro somente quando uma leitura por colunas ajudar; ele não é obrigatório e não deve ser tratado como cadastro separado.

## Apresentações e Radar NectaNet

- **Pronto para apresentar** é uma liberação humana explícita. Não é calculada automaticamente por score ou nível de idioma.
- **Radar NectaNet** é uma classificação de oportunidade/parceiro. Não é etapa do Talento e não libera apresentação.
- Para descobrir o que fazer, use a ficha → **Revisar liberação** e registre a próxima ação na seleção/agenda.

## Organizacional

Use **Empregadores** para o dossiê da parceria. Cada empregador recebe uma cor estável apenas para localização visual. Use **Oportunidades** para vagas e **Seleções** para os Talentos relacionados; não replique o mesmo dado em texto livre.

## Atalhos

- `/` foca a busca da área;
- `Ctrl+K` ou `⌘K` abre ações rápidas;
- `Esc` fecha popup ou painel lateral;
- em tabelas, clique na linha para abrir a prévia quando houver um detalhe disponível.

## Limites desta homologação

Não há sincronização com Google Planilhas, backup remoto, Google Drive ou armazenamento paralelo. O Supabase é a fonte de dados. A homologação usa dados reais somente quando o repositório estiver conectado ao banco configurado; a prévia é fictícia e descartável.
